# Examples Directory

Reference examples for each type of Copilot customization file. Use these as inspiration — your actual files go in `.github/` of your workspace.

## Contents

| Directory | What's Inside | Used In |
|---|---|---|
| [instructions/](instructions/) | Language-specific instruction examples | Module 2 |
| [prompts/](prompts/) | Prompt files (including full-workflow with variables) | Module 3 |
| [agents/](agents/) | Agent files (including orchestrator with handoffs) | Module 4 |
| [skills/](skills/) | Skill definitions (SKILL.md) | Module 5 |
| [mcp/](mcp/) | MCP server configurations | Module 6 |

## Key Examples for the Workflow

| File | What It Shows |
|---|---|
| `agents/orchestrator.agent.md` | Full orchestrator with 7 stages and handoff format |
| `prompts/full-workflow.prompt.md` | Complete generation prompt with all variables |
| `prompts/scaffold-feature.prompt.md` | Feature scaffolding with variables |

## How to Use

1. **Read** — Understand the structure and patterns
2. **Adapt** — Modify for your chosen app type and framework
3. **Place** — Copy to `.github/` in your workspace (not here)
4. **Test** — Run and iterate until output matches expectations
