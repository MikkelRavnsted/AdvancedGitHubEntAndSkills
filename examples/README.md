# Examples Directory

This directory contains reference examples for each type of Copilot customization.
Use these as starting points or inspiration for your own configurations.

## Contents

| Directory | Customization Type | Module |
|---|---|---|
| [instructions/](instructions/) | Custom instruction files | Module 2 |
| [prompts/](prompts/) | Reusable prompt files | Module 3 |
| [agents/](agents/) | Custom agent definitions | Module 4 |
| [skills/](skills/) | Skill definitions | Module 5 |
| [mcp/](mcp/) | MCP server configurations | Module 6 |

## How to Use These Examples

1. **Read** — Understand the structure and patterns
2. **Copy** — Use as starting points for your own files
3. **Modify** — Adapt to your specific project needs
4. **Test** — Verify they work in your IDE with Copilot

> These are **examples only**. Your actual configurations should be tailored to your team and project.
