# Exercises Directory

This directory is where you create your exercise files during the workshop.

## Guidelines
- Create files with descriptive names (e.g., `02-instruction-comparison.md`)
- Use any programming language you prefer
- Files here can be freely created, modified, and deleted
- Each exercise file should be self-contained

## Module Exercises
- Module 1: `01-my-surfaces.md`
- Module 2: `02-instruction-comparison.md`
- Module 3: Create prompt files in `.github/prompts/`
- Module 4: Create agent files in `.github/agents/`
- Module 5: `05-plugin-design.md`, `05-marketplace-exploration.md`
- Module 6: `06-enterprise-config.md`, `06-security-assessment.md`, `06-hooks-design.md`
- Module 7: Work in the `capstone/` directory
