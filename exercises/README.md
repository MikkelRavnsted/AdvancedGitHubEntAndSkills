# Exercises Directory

This directory is scratch space for testing and iterating during the workshop.

## How to Use This Folder

Use this folder for:
- Testing prompt output before it's final
- Drafting agent instructions before moving to `.github/agents/`
- Notes on what worked and what didn't
- Comparison of different variable runs

## Your Actual Work Goes In

| What | Location |
|---|---|
| Instructions | `.github/copilot-instructions.md` and `.github/instructions/` |
| Prompts | `.github/prompts/` |
| Agents | `.github/agents/` |
| Skills | `.github/skills/[skill-name]/SKILL.md` |
| MCP config | `.vscode/mcp.json` |
| Generated apps | `generated/[appName]/` |
| Capstone notes | `capstone/` |

## Tips
- Name files descriptively: `test-architect-output.md`, `variable-comparison.md`
- Delete freely — this is scratch space
- If you find a good pattern, move it to the proper `.github/` location
